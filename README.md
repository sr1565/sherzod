# Sherzod Ravshanov — Portfolio

A free, responsive personal engineering portfolio for GitHub Pages. Built with plain HTML, CSS, and JavaScript; no build tools, packages, or paid services required.

## Customize BEFORE publishing

1. Open `index.html` in a code editor.
2. Find and replace `YOUR_EMAIL@example.com`, `YOUR_GITHUB_USERNAME`, and `YOUR_LINKEDIN_SLUG` with your details. You can replace the full LinkedIn URL if needed.
3. Edit project descriptions to reflect your current work accurately. Cards currently describe research directions / in-progress exploration, **not verified completed results**.
4. Optional: to add your resume, place `resume.pdf` in the same folder, then add `<a href="resume.pdf" target="_blank">Resume ↗</a>` in the navigation or contact section. Only publish a resume after reviewing personal information in it.
5. Remove the paragraph with class `setup-notice` from `index.html` after updating your links.

## Preview locally

Double-click `index.html` and open it in your browser. No terminal or server required.

## Publish to GitHub Pages (free)

1. Log into GitHub and click **New repository**.
2. Name the repository **YOUR_GITHUB_USERNAME.github.io** (replace the placeholder with your actual GitHub username; spelling must match). Choose **Public**.
3. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `.nojekyll` directly into the repository root (not nested in a folder). Commit changes.
4. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Select **main** and **/(root)**, then click **Save**.
5. Open `https://YOUR_GITHUB_USERNAME.github.io/`. Publishing can take several minutes.

## Update later

Edit files in the repo and commit. GitHub will republish the site automatically.

## Notes

- Everything works on static hosting. No backend, database, analytics, or trackers.
- This is your public website. Avoid uploading home address, phone number, private documents, unpublished confidential research, or sensitive contact information.
- Projects are intentionally labeled as in progress or explorations; replace with verified results and screenshots when available.
